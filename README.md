# 🚌 Bus Booking & Management System

A web-based Bus Booking and Seat Reservation System developed using **PHP**, **MySQL**, **HTML/CSS**, and **JavaScript**. This application provides a seamless experience for passengers to search routes and book seats online, while allowing administrators to manage buses, schedules, and bookings.

> 🚧 **Project Status: Active Development (Ongoing)**  
> This project is currently under active development. New features, UI improvements, and database optimizations are being added regularly.

---

## 🌟 Key Features

### 🟢 Completed Features
- 👤 **User Management**: Passenger registration, login, and profile management.
- 🚌 **Bus & Route Management**: Admin controls to add buses, set routes, fare prices, and manage departure schedules.
- 💺 **Interactive Seat Booking**: Real-time seat selection with availability status indicators.

### 🔄 Ongoing & Upcoming Features
- 💳 **Online Payment Integration**: Integrating payment gateways for instant ticket booking.
- 📱 **SMS / Email Notifications**: Automated booking confirmation details sent to passengers.
- 📊 **Advanced Admin Analytics**: Detailed reports for seat occupancy and revenue generated.
- 🎨 **UI/UX Enhancement**: Improving responsive design for mobile and tablet devices.

---

## 🛠️ Tech Stack & Tools

- **Backend / Server-side**: PHP
- **Frontend**: HTML5, CSS3, JavaScript, Bootstrap / Tailwind CSS
- **Database**: MySQL
- **Local Server Environment**: XAMPP / WAMP / MAMP (Apache Web Server)
- **Code Editor**: Visual Studio Code
